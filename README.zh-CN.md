# 股票账本（Stock Ledger）

[English](README.md) | **简体中文**

一个简单的本地券商账户记账软件：记录现金余额、持仓，以及每笔交易的成本和盈亏。
只用 Python 标准库（tkinter 界面 + sqlite3 数据库），数据保存在你自己的电脑上。
会发送到网上的只有两样东西：你的股票代码（用于获取实时价格），以及你在代码框里输入的内容（用于提示匹配的股票）。两者都可以关闭。

## 功能

- Robinhood 风格的界面：深色模式（也可切换浅色），大字显示总资产，下方是资产走势图
  （1天 / 1周 / 1个月 / 3个月 / 今年 / 1年 / 全部），鼠标移到图上可查看任意时刻的数值；右侧“股票”列表
  显示每只持仓今天的迷你走势图和价格
- 多账户（例如 Fidelity 个人账户和 Roth IRA）；新建账户时可以填写期初现金和期初持仓
- **全部账户**视图：有两个或更多账户时，可以把它们加在一起看总净资产，并有各账户明细表和跨账户合并的持仓
- 交易类型：存入、取出、买入、卖出、股息、利息、费用、股份转入、股份转出、拆股、代码变更、派发
- 除了股票也能记加密货币：比特币记为 `BTC-USD`（以太坊 `ETH-USD`，依此类推），数量精确到 0.00000001
- 自动计算现金余额（含每笔交易后的余额）、持股数、平均成本、持仓成本、已实现盈亏和累计股息
- 单只股票详情：双击股票可查看它的每一笔交易，以及每笔交易后的持股数和平均成本
- 每 10 秒从 Yahoo Finance 获取实时价格：市值、未实现盈亏、今日涨跌和总资产随行情变化；
  开盘期间，今天走势线的末端有一个闪烁的圆点标出最新价格（总资产曲线、个股页曲线，以及股票列表里每只股票的小曲线上更小的圆点），
  和 Robinhood 一样
- 关闭实时报价即可完全离线使用，改为手动填写价格
- 像 Robinhood 一样边输入边搜索股票：输入代码或公司名称（如“apple”“berkshire”），用鼠标或 ↑↓ + 回车
  从列表中选择。已持有的股票排在最前并显示股数；打开实时报价时，其他匹配结果来自 Yahoo
  （离线时只提示本账户的股票）
- 交易记录页的**时间范围**筛选：过去一个月、3 个月、6 个月、一年、某个自然年，或者自己输入起止日期
- **财务收支**页（可选功能，默认关闭，在 ⋯ 菜单里打开）：记录股票账户之外的钱，按月统计的收支表（像 Excel 一样），余额逐月自动承接，
  收入和支出项目可以自己增减，金额可以直接写算式（`1250.50+1250.50`），每一项金额都能加注释，
  还可以选任意一段月份（比如报税年度、自定义起止月份）看各项合计，方便和报税表核对
- 记错了双击即可修改或删除，所有数字自动重算；前后矛盾的记录（比如卖出多于持有的股数）会被拒绝
- 可调字号（⋯ 菜单 → 字号：小 / 标准 / 大 / 特大）
- 中英文界面（⋯ 菜单 → Language / 语言）；第一次启动时默认为中文
- 导出 CSV（可直接用 Excel 打开）、手动备份数据库、每天自动备份

## 1. 在 WSL 中搭建开发环境

**1. 把项目放进 WSL**（在 WSL 终端里操作，假设 zip 下载到了 Windows 的“下载”文件夹）：

```bash
cd ~
cp /mnt/c/Users/<你的 Windows 用户名>/Downloads/stock_ledger.zip .
unzip stock_ledger.zip
cd stock_ledger
```

**2. 创建 conda 环境**（要用 `xft` 版本的 Tk，它在 Linux 上能使用真正的平滑字体）：

```bash
conda create -n stockledger -c conda-forge python=3.12 "tk=8.6.*=xft*" xorg-libxft -y
conda activate stockledger
python -c "import tkinter; tkinter._test()"   # 弹出一个小窗口，说明图形界面正常
```

**3. 安装中日韩字体**：使用中文界面，或者账户名称、备注里有中日韩文字时需要安装，否则在 WSL 里会显示成方框：

```bash
sudo apt update && sudo apt install -y fonts-noto-cjk
```

**4. 用 VS Code 打开**：

- 在 Windows 的 VS Code 中安装 **WSL**（Microsoft 出品）和 **Python** 扩展
- 在 WSL 终端进入项目文件夹，运行 `code .`，VS Code 会以 WSL 模式打开（左下角显示 `WSL: Ubuntu`）
- 第一次打开后，在扩展视图里为 WSL 也安装一次 Python 扩展
- `Ctrl+Shift+P` → `Python: Select Interpreter` → 选择 `stockledger` 这个 conda 环境

## 2. 运行和调试

```bash
conda activate stockledger
python app.py          # 启动软件（窗口会通过 WSLg 显示在 Windows 桌面上）
python test_ledger.py  # 运行测试，检查计算是否正确
```

也可以在 VS Code 中打开 `app.py`，按 `F5` 带断点运行。

开发期间，数据保存在 `stock_ledger/data/stock_ledger.db`。

## 3. 打包成 Windows exe

> PyInstaller 不能跨平台打包：在 WSL（Linux）里打包只能得到 Linux 程序。
> 所以代码在 WSL 里写，但**打包这一步要用 Windows 版 Python**。这只需要设置一次。

**1. 在 Windows 上安装 Python**（只需一次）

从 <https://www.python.org/downloads/windows/> 下载 Python 3.12 或更新版本并安装。
安装时勾选 **Add python.exe to PATH**，其他保持默认即可（默认已包含 tkinter）。

**2. 打包**，两种方法任选一种：

方法 A：在 WSL 终端里运行一条命令（VS Code 的终端也可以）：

```bash
bash build_from_wsl.sh
```

它会把源代码复制到 `C:\Users\<你>\StockLedgerBuild`，用 Windows 版 Python 安装 PyInstaller 并打包，
完成后打开包含 `StockLedger.exe` 的 `dist\StockLedger` 文件夹。

方法 B：把 `app.py ledger.py finance.py csv_export.py storage.py quotes.py ui.py i18n.py icon.ico build_exe.bat` 复制到 Windows 上的一个文件夹里，双击 `build_exe.bat`。

第一次打包要下载 PyInstaller，大约 1～2 分钟；之后会快很多。

**3. 使用 exe**

打包结果是一个文件夹 `dist\StockLedger`：里面有 `StockLedger.exe` 和它需要的 `_internal` 文件夹
（Python 和 Tk 都在里面，所以电脑上不需要安装 Python）。文件夹形式比单文件 exe 启动更快
（单文件 exe 每次启动都要先解压到 `%TEMP%`），也更少被杀毒软件误报。

把整个 `StockLedger` 文件夹复制到固定位置，例如 `D:\StockLedger\`，双击 `StockLedger.exe` 即可运行
（右键 → *发送到 → 桌面快捷方式* 可以创建桌面图标）。
窗口启动时就是最大化的，点还原按钮可以回到普通大小。
数据保存在 exe 旁边的 `data` 文件夹。更新时，删掉旧的 `StockLedger.exe` 和 `_internal`，复制进新的，
`data` 文件夹不要动。（重新打包也不会碰 `dist\StockLedger` 里的 `data` 文件夹。）

## 4. 数据和备份

- 所有数据都在一个文件里：`data\stock_ledger.db`。复制这个文件就是完整备份。
- 每天第一次打开软件时，会自动备份到 `data\backups\`，保留最近 30 天。
- **⋯ → 备份数据库** 可以随时备份到任意位置（例如云同步文件夹）。
- **⋯ → 导出当前账户为 CSV** 会导出该账户的三张表（交易记录、持仓、年度汇总）；打开财务收支页之后，**⋯ → 导出财务收支为 CSV**
  会导出财务收支表的三张表。都可以直接用 Excel 打开，各列的含义见 [CSV 文件](#csv-文件用于分析和核对报税)。
- 要把在 WSL 里测试时录入的数据带到 exe，把 `data/stock_ledger.db` 复制到 exe 旁边的 `data` 文件夹即可。

## 5. 实时价格

- 顶栏的 **实时** 开关控制是否自动更新（下次打开时会记住）。
- 价格每 10 秒刷新一次（`app.py` 中的 `LIVE_INTERVAL`）。开关旁边显示最后一次更新的时间。
- 持仓表的 **今日涨跌** 列和 **总资产** 下方的“今天”一行，显示相对前一交易日收盘价的变化。
- 数据来自 Yahoo Finance。美股接近实时；部分其他交易所最多延迟 15 分钟。
  非交易时间显示最近的收盘价。
- 闪烁的圆点只在开盘时显示。美股和 ETF 按纽约时间的交易日 9:30–16:00 算开盘（少数提前收盘的日子到 13:00），
  与你电脑所在的时区无关；周末、休市日、开盘前和收盘后都不显示。加密货币不收盘，圆点一直闪。
  总资产曲线上的圆点，在你的持仓中任何一只正在交易时就会闪。
- Yahoo 不认识的代码（例如定期存单、私募基金）会显示“无报价”，请用 **更新价格** 手动填写。
- 股票类别两种写法都可以：`BRK.B` 和 `BRK-B` 都行。
- 加密货币写成“币种-USD”：`BTC-USD`、`ETH-USD`、`SOL-USD`（搜“bitcoin”或“btc”就能找到）。
  只写 `BTC` 是另一样东西：在股市交易的比特币 ETF。加密货币 24 小时交易。
- 新代码（改代码后，或者新上市的认股权证等）只要 Yahoo 开始收录就能获取实时价格；
  在那之前显示“无报价”并按成本计算，也可以用 **更新价格** 手动填写价格。
- 断网时会保留最后取到的价格，并自动重试。

**走势图**

- 大字数字是你的总资产（现金 + 持仓）。鼠标移到图上可查看任意时刻的数值。
- 1天 与前一交易日收盘价（虚线）比较。其他范围显示这段时间的盈亏，并扣除了存入和取出的资金，
  所以存钱进来不会被算作收益。
- 过去的数值由你的交易记录和 Yahoo 的每日收盘价重新算出，并考虑了你记录过的拆股。
- 有两个或更多账户时，账户菜单最上面的 **全部账户** 会把它们加在一起：显示净资产和走势图；**账户** 页列出每个账户的现金、
  市值、占总额的比例和盈亏（双击某个账户可打开它）；**持仓** 页按股票代码合并（同一只股票在两个账户里算一行，
  平均成本 = 总成本 ÷ 总股数）。这个视图是只读的：添加或修改交易请先选一个具体账户。所有金额按美元计算，没有汇率换算。
- 点击 **股票** 列表中的股票（或在“持仓”页双击），主区域会切换成该股票的详情页，查看价格走势、你的持仓和交易历史。
  在右侧列表里点另一只股票可直接切换；点 **返回** 或按 `Esc` 回到总览。
- **⋯ → 深色模式** 切换深色和浅色主题；**⋯ → Language / 语言** 切换中英文。

## 6. 各种情况怎么记

| 情况 | 记为 |
|---|---|
| 开始记账时账户里已有的现金 | 新建账户时填期初现金（或记一笔存入） |
| 开始记账时已持有的股票 | 新建账户时填期初持仓（或记一笔股份转入，填每股成本） |
| 从银行转入 / 转出到银行 | 存入 / 取出 |
| 买入 / 卖出股票 | 买入 / 卖出（填数量、价格和手续费，现金自动更新） |
| 现金股息 | 股息（填金额） |
| 股息再投资（DRIP） | 先记一笔股息，再记一笔买入 |
| 现金利息（例如 SPAXX 收益） | 利息 |
| 账户费用、ADR 费用等 | 费用 |
| 拆股（1 拆 4：10 股变 40 股） | 拆股，填 **30**（增加的股数）；总成本不变 |
| 合股（反向拆股） | 拆股，填负数 |
| 股票转到其他账户 | 股份转出（按平均成本减少持仓，不产生盈亏） |
| 股票改代码，或合并时换成新股票 | 代码变更：填原代码、新代码和换得的新股数（一换一点 **全部**）；持仓成本一并转过去，不产生盈亏 |
| 分拆，或免费派发的认股权证 / 配股权（例如每股送 1 份权证） | 派发：填原股票代码、新证券代码、获得数量，以及从原股票持仓成本中转过去的比例（不清楚就填 **0**，见下文）；不产生盈亏 |
| 买卖加密货币 | 买入 / 卖出，代码填 `BTC-USD` 等 |

**持仓成本按平均成本法计算**：买入时加上成本（含佣金）；卖出时按当时的平均成本扣除成本，
已实现盈亏 = 卖出所得 − 扣除的成本。支持零碎股。

**派发的成本比例**：填 0% 时总盈亏是对的，但权证的全部市值会显示为它自己的盈利，而股票保留全部成本。
如果公司公布了成本分摊（美国国税局 Form 8937，例如“x% 分给权证”），编辑这笔派发、填上这个比例即可：
股票的成本相应调低，权证分得这部分成本。

小技巧：
- `Ctrl+N` 添加交易；在“交易记录”页选中一笔后，按 `Enter` 编辑，按 `Delete` 删除
- 点击列标题可以排序。窗口太窄放不下所有列时，表格可以左右滚动（表格下方的滚动条，或 `Shift` + 鼠标滚轮）；窗口太矮时，整个页面可以上下滚动（右侧滚动条，或鼠标滚轮）
- “交易记录”页的 **时间范围** 可以只看过去一个月、3 个月、6 个月、一年、某个自然年（列出有交易的年份），或选 **自定义范围…**：
  输入起始和/或结束日期（例如 `2026-01-01`，其中一个留空表示不限；日期看不懂时输入框会变红）。它可以和“代码”“类型”筛选一起用，
  “现金余额”一列仍然是整个账户的累计余额
- **重置筛选**（设置了任何筛选时才显示）只会清除筛选条件，不会删除任何交易
- 卖出时点 **全部**，自动填入当前持有的股数
- 同一天的交易按录入顺序处理

## 财务收支页（股票账户之外的钱）

这个页面是**可选**的。不勾选 **⋯ → 财务收支页** 时，它完全不存在：没有按钮，数据库里也不会多出任何表，股票部分的界面和功能和以前一模一样。
再次取消勾选就会把这个页面隐藏起来，已经录入的数据仍然保留。

打开之后，账户菜单旁边会出现 **财务收支** 按钮，点开是一张按月统计的收支表，记录和股票账户无关的收入与支出（工资、银行利息、信用卡还款、税款……）。
格式和 Excel 表格一样：每个月一行，依次是 **起始资金**、你的各个收入项目、**收入合计**、各个支出项目、**支出合计**、**月末结余**
（月末结余 = 起始资金 + 收入 − 支出）。每个月的起始资金自动承接上个月的月末结余，所以余额就是你所有银行账户的总和，
不需要一个个列出账户。点 **返回** 或按 `Esc` 回到股票界面。

- **+ 添加月份**（或双击某个月份编辑）：每个项目一行，可以填 **金额** 和 **注释**。金额可以是算式，例如
  `1250.50+1250.50` 或 `120.40+85.25-10.15`；各项会保留下来，选中月份后在表格下方查看。第一个月需要填 **起始资金**，
  之后的月份留空即可承接上月（如果和银行实际余额对不上，可以直接填一个数来校正）。
- **注释**：每一项金额都可以加注释（可以写多行）。金额前面带 **•** 的格子表示有注释；选中该月份，在表格下方的框里查看注释和算式。
- **收支项目…**：增加、重命名、调整顺序、删除收入和支出项目。删除一个项目，也会删除它的金额和注释。
- **时间范围** 选择要看的月份：全部时间、过去 3 个月、过去 6 个月、过去一年（含本月）、某个自然年（列出有月份的年份），
  或 **自定义范围…**，填起始月份和结束月份（`2026-01`；填完整日期如 `2026-03-31` 也行，按它所在的月份算；留空表示不限；
  看不懂的内容会让输入框变红）。表格、**合计** 行、表格上方的汇总数字和 **所选时段合计** 都跟着它变。
- **所选时段合计** 列出所选月份里每个收入、支出项目各自的合计，以及收入合计、支出合计和覆盖的起止月份——
  比如选某一年，就可以拿总收入、利息收入、已缴税款去和报税表核对。
- **全部账户**视图：开启财务收支页并且至少录入了一个月之后，这里的净资产会把财务收支的现金结余（最新一个月的月末结余）也算进去。
  图表上方有一块并排显示各部分：**净资产（全部账户）** = **股票账户净资产** + **财务收支现金结余**，以及 **股票账户现金**
  （它已经包含在股票账户净资产里，不会重复相加）。图表和下面的各项数字只针对股票账户。关闭财务收支页，或者只看某一个账户时，一切照旧。

## CSV 文件（用于分析和核对报税）

每个文件都是一张规整的表：一行表头，每条记录一行，中间没有空行、标题行或合计行，所以 Excel 可以直接筛选、做数据透视表和求和。
日期是 `YYYY-MM-DD`，金额是纯数字（`1234.50`，没有千位分隔符），不适用的格子留空，列标题跟随界面语言。
文件名是 `<名称>_<表>_<日期>.csv`，保存为带 BOM 的 UTF-8，Excel 打开中文不会乱码。导出的是全部数据（所有年份），
要看某个报税年度，用 **年度** 这一列筛选即可。

**⋯ → 导出当前账户为 CSV**（某一个股票账户；“全部账户”视图下不可用）

| 表 | 每行是 | 列 |
|---|---|---|
| `transactions` | 一笔交易，旧的在前 | 账户、日期、年度、类型、代码、新代码、数量、价格、转移成本比例、手续费、金额、现金变动、现金余额、卖出净所得、卖出成本、已实现盈亏、备注 |
| `holdings` | 一个持仓（已清仓的也有），最后是现金 | 账户、截至日期、代码、股数、平均成本、持仓成本、价格、市值、未实现盈亏、已实现盈亏、股息 |
| `yearly` | 有交易的一个自然年 | 账户、年度、存入、取出、股息、利息、账户费用、交易手续费、卖出净所得、卖出成本、已实现盈亏 |

- **金额** 是存入、取出、股息、利息、费用本身的数额。**现金变动** 是这笔交易让现金增加或减少了多少（负数 = 减少），**现金余额** 是之后剩下的现金。
  拆股的 **数量** 是股数的变化；派发的 **转移成本比例** 是转给新证券的那部分持仓成本占比（它不是价格）。
- 只有卖出才有 **卖出净所得** = 数量 × 价格 − 手续费（1099-B 上的数字）、**卖出成本** = 卖出那部分股票的平均成本（相当于 1099-B 的成本）、
  **已实现盈亏** = 卖出净所得 − 卖出成本。`holdings` 里的 **持仓成本** 则是现在持有部分的成本。
- `holdings` 最后一行是现金（它的 **市值** 就是现金余额），所以市值这一列加起来就是账户的总价值；没有价格的股票没有市值。
  价格是导出当天（**截至日期**）软件里的价格。
- `yearly` 用来和 1099-DIV（**股息**）、1099-INT（**利息**）、1099-B（**卖出净所得**、**卖出成本**、**已实现盈亏**）核对。
  **账户费用** 是单独记的费用，**交易手续费** 是买卖时付的手续费。平均成本法没有每一批股票的买入日期，所以它本身不能直接当 Form 8949 用。

**⋯ → 导出财务收支为 CSV**（打开财务收支页后才有；支出也是正数）

| 表 | 每行是 | 列 |
|---|---|---|
| `monthly` | 一个月 | 年度、月份、起始资金、*你的各个收入项目*、收入合计、*你的各个支出项目*、支出合计、月末结余 |
| `yearly` | 有月份的一个自然年 | 年度、月数、起始资金、*你的各个收入项目*、收入合计、*你的各个支出项目*、支出合计、月末结余 |
| `entries` | 一笔录入的金额 | 年度、月份、类型（收入 / 支出）、项目、金额、算式、注释 |

- `monthly` 就是页面上那张表的样子。`yearly` 列相同，但按年汇总：**月数** 是已录入的月份数（12 = 整年都录了），
  **起始资金** 取该年第一个月的，**月末结余** 取最后一个月的；某个项目这一年一笔都没有就留空。
- `entries` 是同样的数据，一笔金额一行，带上你输入的算式（`4000+4000`）和注释——适合按项目做透视表，
  或者查某条注释写了什么（比如所有标记为税款的付款）。

## 7. 常见问题

**在 WSL 里运行 `python app.py` 没有窗口**
需要 WSLg（Windows 11 自带；Windows 10 需要较新的版本）。在 Windows PowerShell 中运行 `wsl --update`，然后 `wsl --shutdown` 重启 WSL 再试。

**WSL 里字体很小、有锯齿，或者某些符号显示成 `\u25be`**
你的 Tk 是 `noxft` 版本，在 Linux 上用不了真正的字体。换成 `xft` 版本：
`conda install -n stockledger -c conda-forge "tk=8.6.*=xft*" xorg-libxft`。
这只影响开发时的显示；exe 在 Windows 上使用 Segoe UI（中文界面使用微软雅黑）。

**Windows Defender / 杀毒软件报毒**
PyInstaller 打包的未签名程序偶尔会被误报（文件夹形式比单文件少得多）。可以在 Defender 中把 `StockLedger` 文件夹加入排除项。
第一次运行时 SmartScreen 可能提示“Windows 已保护你的电脑”：点 *更多信息 → 仍要运行*。

**我想要红涨绿跌**
打开 `ui.py`，把开头附近的 `RED_UP` 改成 `True`，重新打包即可。（主题颜色在同一文件的 `PALETTES` 中。）

**添加或修改界面文字**
在代码里用 `tr()` 包住英文文字，例如 `tr("Cash")` 或 `tr("{n} transactions", n=count)`，
再把中文加到 `i18n.py` 的 `ZH` 表里。如果有文字缺少翻译，或者翻译里的 `{占位符}` 对不上，`python test_ledger.py` 会报错。
